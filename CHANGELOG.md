## v0.3.0

- Delegate decisions in Codex or Claude Code with the optional
  `atd-developer-proxy` skill. Approving an approach leaves alternatives open.
  Changing acceptance criteria requires explicit agreement on the wording and a
  concrete example whose acceptance would change.
- When a verification gate needs attention, `atd verify` reports both gate
  results and gives the commands to rerun the affected suites.
